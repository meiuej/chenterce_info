# Анимированный заголовок

Текущий сайт — статический HTML, без npm, React, TypeScript и Tailwind. Главный заголовок работает через `assets/text-dia.js`, стили находятся в `donation.css`; общие стили — в `centerce-base.css`. Для действующей страницы установка npm-пакетов не нужна.

`text-dia.tsx` и `demo.tsx` — версия для будущего React-приложения. Компонент принимает массив слов, интервал в миллисекундах и стандартные атрибуты span. Провайдеры, картинки и иконки не нужны. Ширина резервируется под самое длинное слово. При reduced motion смена отключается.

## Подключение в React

Создайте отдельный проект через `npx shadcn@latest init` и выберите TypeScript и Tailwind в настройках проекта. Затем выполните `npm install motion`. Скопируйте компонент в `components/ui` (или `src/components/ui`, если alias `@` указывает на `src`). Путь определяется настройкой `aliases.ui` в `components.json`.

Папка `components/ui` нужна для общего хранения UI-компонентов и согласованных импортов shadcn. Убедитесь, что `@/lib/utils` экспортирует `cn`, а глобальный CSS проекта подключает Tailwind. Импортируйте `DiaText` из `@/components/ui/text-dia` и передайте `words={["независимость", "правду", "Россию"]}`.
